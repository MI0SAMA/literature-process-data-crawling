# 双人标注操作指南

## 1. 打开网页

服务已按局域网方式启动，监听 `0.0.0.0:8767`：

- 本机：**http://127.0.0.1:8767/**
- 同一局域网同事：**http://<LAN-IP>:8767/**

不再需要账号密码。打开页面后，在左上角**输入自己的姓名**即可开始；姓名会随每次保存写入数据库，用于进度和差异对比。

A/B 的独立性靠流程保证：两个人分别使用，不要互相看屏幕；不要用对方姓名填写。

如果服务停了，在项目目录运行：

```powershell
python tools/annotation_app.py --host 0.0.0.0 --port 8767
```

> 因为已去掉登录，任何能访问 8767 的人都可以填写和下载 PDF。只允许在可信内网使用，不要映射到公网。

### 让同事能访问

当前 Windows 防火墙尚未放行 8767；如果同事打不开，请用**管理员 PowerShell**执行：

```powershell
New-NetFirewallRule -DisplayName "AlScN Annotation 8767" -Direction Inbound -Protocol TCP -LocalPort 8767 -Action Allow -Profile Private
```

只在可信内网使用；不要把 8767 映射到公网。若同事不在同一局域网，使用 VPN/Tailscale，不要直接公网暴露论文 PDF。

## 2. 标注流程

1. 标注者 A 在左上角输入自己的姓名。
2. 在左侧选择 `OD-01` 开始。
3. 在页面内查看 PDF；可展开“PDF 前 4 页文本”搜索关键词。
4. 按字段填写，保存。
5. 点“下一条”继续。
6. 标注者 B 独立做一遍，输入自己的姓名，不要参考 A 的填写。
7. 两人都完成后，打开 **A/B 对比** 查看差异。
8. 分歧由第三人裁决，形成 gold label。

保存是**追加式**的：每次保存都会留下一条 `annotation_actions`，不会覆盖上一次。页面显示的是该标注者最新一版。

## 2.1 一篇论文有多个工艺怎么办

页面现在按 **Recipe 卡片**组织，而不是全篇只有一个工艺：

- 同一篇论文有多个独立沉积条件时，点 **“+ 添加工艺 / Recipe”**，每个工艺一张卡片。
- 每张 Recipe 卡片有自己的：
  - 方法、溅射模式、设备
  - 靶材表（靶材属于该工艺，不再全篇共用）
  - 气压、温度、气体流量、膜厚、时间、靶基距离
  - 本工艺证据
- 不要把一个工艺的靶材填到另一个工艺卡片里。
- 删除某张卡片不会影响其他工艺。
- `recipe 数量` 会随卡片数量自动更新，也可以手填修正。

判定“一个 Recipe”的建议：

- 不同样品但沉积条件相同 → 可以共用一张 Recipe，在论文级备注写样品差异。
- 功率、气压、温度、气体比例、靶材配置任一不同 → 建不同 Recipe。
- 多层结构但同一真空流程连续沉积 → 先作为一张 Recipe，在备注写清层顺序；后续实体模型再拆 Step/Layer。

## 3. 每个字段怎么填

### 论文级

| 字段 | 说明 |
|---|---|
| 相关性 | 是否属于 AlScN/ScAlN PVD/沉积研究 |
| 有可执行 recipe | 是否有足以复现的沉积配方；只有性能/理论/综述选 no |
| recipe 数量 | 论文中实际不同的配方数；不确定写 0/1/2 并在备注说明 |
| 沉积方法细分 | 如 `reactive co-sputtering; pulsed DC` |
| 溅射模式 | DC / RF / pulsed DC / HiPIMS / 混合 |
| 设备型号 | 原文型号；没有写空 |

### 靶材（每张 Recipe 内）

每张工艺卡片内，每个靶材一行：

| 字段 | 说明 |
|---|---|
| 材料 | Al、Sc、AlSc、AlN、Pt 等 |
| 功率 W | 只填原始功率，不要自己换算 |
| 功率语义 | `target_power`（明确靶功率）/ `sputter_power`（原文 sputter power）/ `bias_power` / `power_density` / `unknown` |
| 统计口径 | average / peak / rated / unknown；原文没写就 unknown |
| 直径 mm | 只填靶材直径；不要把靶基距离、厚度填进来 |
| 模式 | 该靶的电源模式 |
| 证据原文 | 直接粘贴支持该行功率/直径的句子 |

### 工艺条件

只填原文明确给出的值；没有就留空，不要用常识补。

- 工作气压 / 本底气压：注意单位与“测试真空腔”区分
- 沉积温度：不要填底电极温度、室温测试、退火温度
- N2 / Ar：注意 `N2:Ar = 160:32` 的对应关系
- 膜厚：只填 AlScN/功能层，不填电极/种子层
- 沉积时间 / 靶基距离：区分刻蚀、预溅射、测试距离

### 证据与备注

- `整体证据`：粘贴方法段关键原句，尤其是层/步骤归属。
- `标注备注`：写不确定点，例如“这段同时描述底电极和 AlScN”“功率是 6 kW sputter power，不是 target power”。

## 4. A/B 对比与裁决

打开：

**http://127.0.0.1:8767/compare**

当前对比会显示：

- 两位标注者是否已提交
- 相关性、recipe、方法、设备是否不同
- 靶材材料+功率集合是否不同

裁决建议：

1. 先看 PDF 原文，不看抽取器输出。
2. 数值不同：以原文明确语义为准，不取平均。
3. 一个标“有”、一个标“无”：检查是否只有引用/综述/摘要值。
4. 记录裁决理由，形成 `gold_standard_v1`。

## 5. 导出

页面右上角 **导出 CSV**；PDF 标题旁有 **下载 PDF** 按钮。

`http://127.0.0.1:8767/export.csv`

数据库：

`data/annotation/testset.sqlite3`

表：

- `annotation_actions`：每次保存的完整 JSON + 时间，append-only

CSV 中 `recipes_json` 是工艺数组，每个工艺内再含 `targets`；后续可展开为 Recipe/Target 长表。

> 下载的 PDF 仅限单位已有访问权的内部科研使用，不要再对外分发。

## 6. 建议的第一批

先做 10 篇：

- 5 篇 `deposition`
- 3 篇 `characterization`
- 2 篇 `theory_or_review` 负样本

完成 10 篇后先算：

- 字段级完全一致率
- 数值差异分布
- “有 recipe / 无 recipe”分歧
- 证据是否支持字段

再决定是否扩到 30 篇。不要用同一批 30 篇反复改规则后再宣称盲测。
